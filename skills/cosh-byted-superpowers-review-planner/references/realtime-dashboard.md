# Superpowers 实时观察板

观察板用于查看和可选控制，不是唯一入口。用户完全不打开页面时，自然语言仍调用同一后端门禁推进流程。

## 启动

运行 `scripts/serve_superpowers_dashboard.py --project <目标仓库>`，默认只监听 `127.0.0.1`。服务发现 `.superpowers/byted-work/` 下的多个开发任务，通过 `?work=<work-id>` 切换。

## 页面

导航包含总览、技术文档、评审、规格、计划、验证和最右侧强调色 Tasks。评审页展示知识模式、三路进度、未通过风险点、证据与建议修改；Tasks 页顶部切换推进模式。

逐一任务校验时，当前任务右上角只保留“推进下一个任务”。连续模式不渲染该按钮。页面不单列 artifacts 或重复展示计划文件中的任务文档。

## 实时性

服务监听原生规格、计划、SDD 进度、字节证据和 Git 状态，通过 SSE 推送版本化快照。前端断线自动重连；版本不连续时全量刷新。原子替换、短暂半写入或解析失败时保留最后有效快照，同时显示阻塞错误，不能把未知状态当成通过。

所有写请求包含 `work`、期望状态版本和幂等键。后端重新校验前置门禁、文档哈希、代码 SHA 和任务范围，拒绝过期或伪造请求。
